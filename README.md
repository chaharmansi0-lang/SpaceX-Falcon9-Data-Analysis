# SpaceX Falcon 9 Data Analysis & Landing Prediction

## Project Overview

This project focuses on analysing SpaceX Falcon 9 rocket launches to understand launch patterns, explore mission data, and investigate the factors influencing first-stage landing success.

The project combines data collection, data wrangling, exploratory data analysis, SQL queries, data visualization, interactive dashboards, and machine learning.

## Project Objectives

- Collect and explore SpaceX Falcon 9 launch data.
- Perform data cleaning and preprocessing.
- Analyse launch records using SQL.
- Explore relationships between launch features and landing outcomes.
- Visualize launch locations and mission trends.
- Build an interactive dashboard.
- Develop machine learning models to predict first-stage landing success.

## Project Workflow

### 1. Data Collection
Collected SpaceX Falcon 9 launch information using API-based data collection and web scraping.

### 2. Data Wrangling
Cleaned and prepared the collected data for analysis.

### 3. Exploratory Data Analysis
Explored launch records, payload information, launch sites, and mission outcomes.

### 4. SQL Analysis
Used SQL queries to investigate launch data and identify useful patterns.

### 5. Data Visualization
Created visualizations to understand launch trends and landing outcomes.

### 6. Interactive Dashboard
Developed an interactive dashboard using Plotly Dash to explore launch records across different launch sites.

### 7. Machine Learning
Applied machine learning techniques to predict Falcon 9 first-stage landing success.

## Dashboard

The interactive dashboard provides insights into SpaceX Falcon 9 launch data, including launch sites and mission outcomes.

## Machine Learning

Machine learning models were developed to analyse and predict first-stage landing success based on available launch features.
